Test: Attempted SSH login using password only (key auth disabled for test)
after applying Control 2 (Enforce SSH key-based authentication).

$ ssh -o PubkeyAuthentication=no snehaadmin@192.168.131.129
snehaadmin@192.168.131.129: Permission denied (publickey).

Note: Initial testing revealed that Ubuntu's cloud-init provisioning
creates a drop-in override at /etc/ssh/sshd_config.d/50-cloud-init.conf
which explicitly sets "PasswordAuthentication yes", overriding the main
sshd_config due to SSH's Include directive processing order. harden.sh
was updated to patch this file as well (Control 2b).

Result: Password authentication fully disabled. Only SSH key-based
login is accepted.
