configured correctly" (which audit.sh verifies) and "system fully
up to date at this exact moment" (a point-in-time state that changes
continuously).

Other suggestions from Lynis (out of scope for this project's 9
controls, noted for context/future work):
  - Set a GRUB bootloader password
  - Configure password hashing rounds and expiry dates in /etc/login.defs
  - Install a malware scanner (e.g. rkhunter, chkrootkit)
  - Consider a separate partition for /home and /var
  - Install libpam-tmpdir, apt-listbugs, apt-listchanges, debsums

These represent a broader hardening scope than this project's 9 defined
CIS-mapped controls and were intentionally left out of scope, but are
worth noting as natural next steps for a production deployment.
